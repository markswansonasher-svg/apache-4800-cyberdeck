Things to try

  1. Start Minecraft → watch the PC wake, load, and “Minecraft is up”.
  2. Add players, then Everyone leaves → it stops by itself after ~1 min and shuts the PC down (the deck woke it).
  3. PC warm → warning. PC overheating → server saved + stopped, then (still hot) the PC shuts down. Press PC cool down before starting again.
  4. EULA off or Wake-on-LAN off, then Start → see the error messages.
  5. Choose Wi-Fi → Hotel Guest → login warning → Travel mode on → Hotel login done.
  6. Players allowed: add a name (try NotARealPlayer for the typo check). With the PC off it's queued and applied when the PC starts.
  7. Pack up with players on → warning, stop, backup, cool-down, PC off → tick the checklist → Shut down the Pi.
  8. Check the deck, then unplug the case cable and check again. Tick “also wake + test the PC” for the arrival check.
